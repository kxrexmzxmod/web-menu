# WorldPanel

WorldPanel เป็นมอด Forge สำหรับ Minecraft Java 1.20.1 ที่เปิดหน้าเว็บควบคุมบน `127.0.0.1` ระหว่างที่ผู้เล่นอยู่ในโลกเท่านั้น คำสั่งเปลี่ยนโลกจะถูกส่งผ่าน Forge SimpleChannel ไปประมวลผลบน Server Thread และตรวจสิทธิ์ OP ซ้ำที่ฝั่งเซิร์ฟเวอร์

## สิ่งที่รองรับ

- Dashboard, สถานะโลก, ผู้เล่น, Game Mode, Weather, Time, Difficulty และจำนวนม็อบใกล้ผู้เล่น
- ค้นหาไอเทมจาก Forge Registry พร้อม pagination และให้ไอเทมเข้ากระเป๋าได้สูงสุด 4,096 ชิ้นต่อคำขอ โดยไม่ทิ้งของส่วนเกินลงพื้น
- เลือกผู้เล่นออนไลน์ที่จะรับไอเทมได้จากหน้าต่าง Give Item; เซิร์ฟเวอร์ตรวจสอบผู้รับและสิทธิ์อีกครั้งก่อนให้ของ
- แสดงไอคอนจาก texture ของ item model ที่ Minecraft โหลดจริง รองรับ resource ของม็อดที่ติดตั้ง และเก็บ cache ในหน่วยความจำเฉพาะ session
- Teleport ตัวเองไปยังผู้เล่นที่ยังออนไลน์
- หน้า Players, Teleport และ Mob Control แสดงรายชื่อผู้เล่นออนไลน์รวมถึงตัวผู้ใช้เอง; การกำจัดม็อบยังไม่สามารถเลือกผู้เล่นเป็นเป้าหมายได้
- นับ/กำจัดม็อบชนิดที่เลือกภายในระยะ 1–128 บล็อก เฉพาะม็อบที่โหลดแล้ว; กันม็อบตั้งชื่อและม็อบเชื่องไว้เป็นค่าเริ่มต้น และจำกัดการกำจัดไม่เกิน 200 ตัวต่อคำขอ
- ปรับ Game Rules ที่ระบุในหน้าเว็บ โดยตรวจชื่อกฎและชนิดค่าจาก allowlist ฝั่งเซิร์ฟเวอร์
- Activity log ในหน่วยความจำของหน้าเว็บปัจจุบัน

## Build

ต้องใช้ JDK 17 แบบ 64-bit และเชื่อมต่ออินเทอร์เน็ตครั้งแรกเพื่อให้ Gradle ดาวน์โหลด dependency ของ Forge:

```powershell
.\gradlew.bat build
```

ไฟล์มอดที่ได้:

```text
build\libs\WorldPanel-1.0.0.jar
```

## ติดตั้ง

1. ติดตั้ง Minecraft Forge `1.20.1-47.4.28`
2. คัดลอก `WorldPanel-1.0.0.jar` ไปยังโฟลเดอร์ `mods`
3. สำหรับ Multiplayer/LAN ให้ติดตั้งไฟล์เดียวกันทั้งฝั่ง Client และ Dedicated Server
4. เปิดเกม Forge และเข้าโลก
5. คลิกลิงก์ **Open WorldPanel** ในแชตเพื่อเปิดหน้าเว็บในเครื่อง
6. ต้องมีสิทธิ์ OP ระดับ 2 ขึ้นไปจึงจะใช้คำสั่งเปลี่ยนแปลงโลกได้

เซิร์ฟเวอร์ Multiplayer ที่ไม่มีมอดฝั่ง Server จะไม่รับคำสั่งควบคุม WorldPanel และหน้าเว็บจะแจ้งว่า Server Mod Missing

## ความปลอดภัยและข้อจำกัด

- HTTP Server bind เฉพาะ IPv4 loopback (`127.0.0.1`) ใช้พอร์ตว่าง และปิดเมื่อออกจากโลก
- Session token สุ่มใหม่ทุกครั้ง อยู่ใน URL fragment เพื่อไม่ส่งไปกับ HTTP request และถูกลบจากแถบ URL หลังหน้าเว็บเริ่มทำงาน
- API ตรวจ Host, loopback, token และ Origin สำหรับคำขอเปลี่ยนแปลง; ไม่มี endpoint สำหรับรันคำสั่ง Minecraft, Java หรือ Shell ทั่วไป
- การให้ไอเทม, เทเลพอร์ต, กำจัดม็อบ, Game Mode, Weather, Time, Difficulty และ Game Rule ตรวจ OP บนเซิร์ฟเวอร์ทุกครั้ง
- การค้นหาม็อบจำกัดอยู่ในระยะผู้เล่นปัจจุบันและไม่ force-load chunk; คำขอกำจัดจำกัด 200 ตัว
- Game Rules ที่หน้าเว็บจัดการได้เป็น allowlist ของกฎ Vanilla ที่รองรับในโค้ด ไม่ได้แสดงกฎที่ม็อดอื่นเพิ่มเอง
- ไอคอนใช้ particle texture ของ baked item model; ไอเทมบางชนิดที่ไม่มี texture จะใช้ไอคอนสำรอง
- Activity Logs เก็บในหน่วยความจำ Browser เท่านั้น และหายเมื่อปิด/โหลดหน้าใหม่

การ build ไม่ได้แทนการทดสอบในตัวเกมจริง ควรตรวจสอบกับโลกสำรองก่อนใช้คำสั่งที่มีผลกับโลก และติดตั้งมอดทั้งสองฝั่งสำหรับ Multiplayer
